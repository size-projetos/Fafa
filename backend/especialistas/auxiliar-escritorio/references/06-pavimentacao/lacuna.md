# Pavimentação — Lacuna de Material

Nenhum dos PDFs fornecidos (pós-graduação, maio/set. 2025-2026) trata
especificamente de dimensionamento de pavimentos (método do DNER/DNIT-ME 09/78,
USACE, ou MeDiNa).

O único conteúdo correlato disponível está em `references/02-geotecnica/crib-sheet.md`,
seção 2.4 (Ensaio de ISC/CBR), que é o parâmetro de entrada básico para
dimensionamento de pavimentos flexíveis, mas não inclui as tabelas ou ábacos de
dimensionamento propriamente ditos.

Para cobrir este domínio de forma equivalente aos demais, recomenda-se buscar:
- Manual de Pavimentação DNIT (IPR-719)
- Manual de Estudos de Tráfego DNIT (IPR-723)
- Método MeDiNa (Método de Dimensionamento Nacional) — IPR/DNIT

Se você tiver esses PDFs, posso processá-los e complementar este domínio da mesma
forma que os demais (crib sheet + figuras técnicas extraídas).
